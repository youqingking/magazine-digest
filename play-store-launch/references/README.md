# Play Store Launch References

This directory is the index for Play Store launch audit/reference material owned by the launch boundary.

Canonical catalog:

- `play-store-launch/references/catalog.json`

Current policy:

- Do not copy app-owned evidence from `docs/launch/`, `docs/privacy/`, or `docs/release/` into this directory.
- Do not treat historical M0/M1/M2/M4/L3 outputs as active runtime source.
- Keep audit/reference docs short and link-oriented if they are added later.
- Keep ordinary user entrypoints in `play-store-launch/README.md` and the main command.
- Use the catalog as an index, not as a copy of long historical docs.
