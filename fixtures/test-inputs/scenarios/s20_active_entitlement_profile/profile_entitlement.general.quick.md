一句话摘要：用户资料页不需要真实账户系统也能先把权益、额度、奖励和未读通知这些聚合视图稳定展示出来。

关键要点：
- active 与 expired 是订阅生命周期语义，grace-like 只是 Stage G 的摘要投影。
- profile 需要把保存数、未读数和奖励摘要放在同一节奏里。
- 真实续费、真实支付和真实 webhook 仍然完全未接入。

为什么重要：
它保证我们在不碰 Stage B canonical contracts 的前提下，把商业展示基础真正接到了 profile 页面。
