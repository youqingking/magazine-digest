# Stage E2 Typography System

## Principles

- Chinese reading first.
- Stable hierarchy over brand expression.
- Slightly warm surfaces plus darker text to reduce glare and improve sustained reading.

## Type Roles

- Title: `40rpx`, weight `700`, line-height `1.3`
- Deck / lead: `32rpx`, weight `500`, line-height `1.75`
- Body: `28rpx`, weight `400`, line-height `1.75`
- Meta: `22rpx`, weight `500`, line-height `1.45`
- Tag / label: `20rpx`, weight `700`, line-height `1.45`
- Quote / emphasis block body: follows body size, but sits inside tinted container or rule
- Empty / state explanation: `24rpx`, weight `400`, line-height `1.6`

## Reading Mode Difference

- `quick_30s`: tighter meta exposure, slightly lighter body emphasis, faster scan rhythm.
- `deep_3m`: stronger body prominence, more generous reading cadence, clearer sectioning for longer passages.

## Body Rendering Baseline

- Title paragraph: supports `#` / `##` style headings.
- Normal paragraph: single-column body copy with high line height.
- List: dash-prefixed items become spaced list rows.
- Guidance block: labeled paragraphs such as `为什么重要:` become tinted helper blocks.
- Quote / emphasis: `>` prefixed paragraphs become restrained quote blocks.

## Chinese Reading Strategy

- Avoid overly light gray body copy.
- Keep one body column and consistent leading.
- Prefer stronger spacing between semantic blocks instead of decorative separators.
- Audience hints stay small and calm so they do not overpower article reading.
