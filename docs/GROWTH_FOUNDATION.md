# Growth Foundation

- Stage G growth surfaces are preview-only and local-runtime-first
- invite, referral, and reward flows are read-model shells, not closed-loop execution
- reward settlement semantics still reference canonical `vip_days`

## Scope

- referral summary preview
- reward summary preview
- invite/share placeholder CTA
- campaign landing placeholder CTA
- admin preview shells for growth inspection

## Explicit Non-Goals

- real referral bind completion
- real reward grant
- real campaign send
- real push or analytics provider integration
