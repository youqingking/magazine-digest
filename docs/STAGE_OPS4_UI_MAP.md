# Stage OPS4 UI Map

## Sections

- Overview
  - current / selected / baseline
  - last publish / rollback
  - candidate readiness
- Content
  - publications
  - issues
  - parser profile
  - overrides
  - taxonomy coverage
- Quality
  - warning budgets
  - accepted anomalies
  - taxonomy drift
  - unmapped sections
- Scenarios
  - scenario catalog
  - compare summary
  - evaluate result
  - release notes / provenance
- Actions
  - action form
  - result console
  - safety notes
- ZIP Intake
  - file upload
  - route hint
  - archive option
  - result console

## UI Rules

- 清晰优先，不追求复杂视觉。
- stateful 动作必须显示 safety note 与 result。
- preview-only / release-candidate / baseline 边界必须显式显示。
