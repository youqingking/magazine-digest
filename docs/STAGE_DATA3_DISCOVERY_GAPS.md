# Stage DATA3 Discovery Gaps

## Feed

- 首页卡片主要展示 publication 与 update type，跨刊时缺少稳定的 section / bucket 语义。
- Barron's 与 Atlantic 并列时，raw section 可读性差异过大。

## Search

- facets 只有 publication / tag / reading mode。
- 跨刊浏览时用户只能靠 raw tag 与 publication key 猜测内容归属。
- publication filter 与 taxonomy-like browsing 无法叠加。

## Detail

- detail 目前只稳定暴露 publication，不足以解释文章处于哪一类 discovery 语义下。
- raw section 若直接展示，会把 publication-specific 杂讯直接暴露给用户。

## Promotion / Ops Visibility

- promotion decision 目前知道 warning / override / gate，但不知道 taxonomy coverage。
- candidate 虽可发布，但缺少“跨刊发现体验是否稳定”的定量可见性。
