# Commercial Foundation

- Stage G commercial surfaces are local-runtime-first and fixture-backed
- canonical money stays `fen`
- canonical discount stays `price_multiplier_basis_points`
- canonical timezone stays `Asia/Shanghai`
- no real payment provider, no real order creation, no real webhook settlement

## Scope

- paywall offer aggregation
- quota status projection
- promo code preview only
- campaign landing display model
- profile benefit aggregation

## Explicit Non-Goals

- real checkout
- real promo redeem
- real entitlement grant
- remote pricing runtime
