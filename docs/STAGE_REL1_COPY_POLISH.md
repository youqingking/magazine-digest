# Stage REL1 Copy Polish

## Must Remove From Normal User Surface

- preview_only
- current / selected
- canonical
- pipeline
- runtime source mode
- scenario id
- promotable / blocked / hold_warning
- warning taxonomy
- override drift

## Allowed To Keep

- publication 官方英文名
- 文章原始英文标题
- 必要英文专有名词

## Page-level Direction

- feed
  - 保留内容入口语气，移除 runtime / foundation 直出
- search
  - 强调“来源/主题/栏目”，弱化 follow/runtime/internal alias 解释
- detail
  - 只保留阅读模式与内容信息，不把 access/runtime/internal 词扔给读者
- paywall
  - 改成“订阅说明/权益预览/邀请奖励”，不再露出 preview-only/provider/campaign route
- profile
  - 改成“阅读权益/设备与账号/消息与收藏”，不直出 Stage/H0/H1a/runtime
- settings
  - 主体中文化；dev-only 才显示 source/release/channel 诊断
