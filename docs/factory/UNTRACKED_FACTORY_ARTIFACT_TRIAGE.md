# Untracked Factory Artifact Triage

## Purpose

Classify factory, launch, harness, prompt, skill, eval, Agno, and agent-tooling
artifacts before opening the Phase A Harvest PR from
`codex/phase-a-factory-assets`.

This report does not adopt product features, service setup, production config,
credentials, applied migrations, fixture source data, generated runtime outputs,
broader old App Factory packs, launch-prep packs, or Agno orchestration runtime
work.

## Evidence

Current cleanup evidence:

- `git status --short --branch --untracked-files=all` reported no untracked
  files before cleanup.
- `git ls-files --others --exclude-standard` reported no untracked files before
  cleanup.
- `git diff --name-status main...HEAD` showed older broad-pack files, tracked
  root generated output under `artifacts/**`, and placeholder `.gitkeep` files
  in the branch history.
- Owner decision: use a narrow PR and do not adopt broader old packs now.

The original untracked artifact concern is no longer represented by `??` files
in this worktree. The cleanup risk is now committed branch scope: broad source
packs and generated-style outputs must be absent from the final PR diff, not
hidden with `.gitignore`.

## Classification Model

| Classification | Meaning |
| --- | --- |
| `adopt_now` | Intentional source asset for the narrow Phase A Harvest PR. |
| `archive_later` | Useful candidate that should be split to a later harness, launch-prep, eval, or Agno review. |
| `ignore` | Obvious generated or local noise that should stay ignored. |
| `local_only` | Generated/local output that may exist during validation but should not be part of the PR. |
| `needs_human` | Requires an owner decision before adoption. |
