# 产品需求文档

## 1. 产品定位

- 面向中国市场，安卓优先。
- 服务对象是“注意力有限但仍需要高质量内容”的用户。
- App 负责消费已经由外部流水线生产完成的内容，不负责 PDF 解析、网页抓取、Prompt 生成或 Markdown 生产。
- 技术基座采用 `uni-starter v2 + uni-admin + uniCloud（阿里云优先）+ schema2code`。

## 2. V1 目标

- 让用户在 `30 秒` 和 `3 分钟` 两种模式下完成高质量阅读。
- 支持 `成人版` 与 `青少年版` 的内容变体。
- 支持动态运营配置，避免版本发版才能改活动。
- 提供 Web 后台支撑内容、活动、券码、实验与风控。
- 支持裂变、代金券、兑换码、防刷。
- 提供埋点、A/B、Push、缓存、断网可读能力。

## 3. 非目标

- 本仓库不实现内容生产流水线。
- V1 不做互动问答、知识图谱、TTS、复杂推荐算法。
- 详细列表见 `docs/OUT_OF_SCOPE.md`。

## 4. 用户与场景

### 4.1 目标用户

- 通勤、排队、碎片化时间阅读用户。
- 希望快速获取重点，但仍接受高质量表达的用户。
- 青少年用户及其监护场景。

### 4.2 核心场景

- 用户在 `30 秒模式` 快速看结论与要点。
- 用户在 `3 分钟模式` 获取更完整背景、论据和行动建议。
- 运营根据产品线 `product_key` 选择不同内容、活动、实验、Push 文案。
- 用户弱网或离线时继续查看最近缓存内容。

## 5. V1 范围

### 5.1 客户端能力

- 首页内容流与详情页只保留治理要求，不在本轮实现正式页面。
- 阅读模式切换：`30 秒 / 3 分钟`。
- 内容变体切换：`adult / teen`。
- 本地缓存：最近访问内容、首屏配置、实验分桶结果。
- Push 跳转协议预留。
- 埋点采集与实验曝光接口约定。

### 5.2 后台能力

- 内容元数据管理。
- 运营配置管理。
- 实验管理。
- 券码、代金券、兑换码管理。
- 裂变任务与风控规则管理。

### 5.3 平台能力

- `product_key` 全链路透传。
- schema 驱动的数据定义与 codegen。
- uniCloud 阿里云环境优先。
- 审计日志、配置版本、灰度开关。

## 6. 关键业务约束

- 所有核心数据表、配置表、事件表必须包含 `product_key`。
- 运营参数、实验开关、风控阈值禁止硬编码。
- 外部内容仅作为已完成输入接入，本仓库不实现内容抓取和生成。
- 青少年变体必须可单独审核、上架、下架。

## 7. 成功指标

- 阅读首屏可用时间满足移动端轻量目标。
- 30 秒模式完成率高于 3 分钟模式。
- 弱网下最近缓存内容可读。
- 运营配置改动无需重新发版即可生效。
- 券码、裂变与防刷链路具备可观测性。

## 8. 验收口径

- 文档层明确模块边界、数据契约、运维要求、Harness 校验方法。
- 样例夹具覆盖双模式 + 双变体。
- Harness 能输出环境缺口与人工依赖清单。
