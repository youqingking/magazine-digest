# Stage DATA1A Pilot Ops Scope

## Included

- 一个单刊单期导入脚本
- 一个 issue manifest
- 一组稳定可回放 normalized article JSON
- 一个 runtime bundle 输出到 `mobile/fixtures/runtime/current`
- 一个 parse report / smoke report
- manifest 级别的 `status` 字段作为最小发布/下线标记

## Excluded

- full CMS
- admin UI
- editor workflow
- review / approval flow
- RBAC
- remote publishing backend
