# Stage OPS4 Operator Jobs

## Daily Jobs

- 查看 current / selected / baseline 与最近 publish / rollback。
- 查看 publication / issue / scenario catalog。
- 查看 warning / override / taxonomy coverage / release readiness。
- 对 candidate 做 compare / evaluate / dry-run publish。
- 对通过 candidate 执行 apply publish / rollback / retire。
- 查看 release notes / provenance / publish history。

## Script-only Friction Before OPS4

- 需要手动记忆脚本名与参数。
- 需要跨多个 output 目录翻 report。
- scenario / quality / release 信息分散在不同 JSON / markdown。

## After OPS4

- operator 通过统一 web desk 看数据。
- operator 通过同一 action 面板触发脚本。
- action 结果、stdout、report path 在 UI 中汇总显示。
