# 运营与交付

## 1. 运营原则

- 所有运营策略动态配置化。
- 不允许把活动时间、券额、阈值、实验比例硬编码进客户端或后台。
- 青少年版内容单独审核。
- 每次配置发布必须带审计记录和回滚方案。

## 2. 角色分工

- 产品：定义玩法、实验、优先级。
- 运营：维护配置、活动、券码批次、Push 计划。
- 内容审核：审核成人版/青少年版变体。
- 开发：维护模板、schema、云端逻辑、客户端壳层。
- QA：校验配置生效、回滚、离线与风控场景。

## 3. 发布流程

1. 外部内容流水线产出标准化内容。
2. 运营导入内容元数据与变体正文。
3. 审核通过后按 `product_key` 发布。
4. 配置、实验、Push、券码分开发布并保留版本。
5. 发布后观察埋点、风险事件、缓存命中与 Push 到达率。

## 4. 日常运营面板

- 内容上架/下架
- 首页运营位
- 默认阅读模式
- 裂变任务开关
- 代金券模板与库存
- 兑换码批次
- 实验状态
- Push 计划
- 风控阈值

## 5. 风险控制

- 新设备高频领券
- 单设备多账号兑换
- 同 IP 异常裂变
- 青少年内容误投成人流量
- 配置误发到错误 `product_key`

## 6. 观测指标

- 内容打开率 / 完读率
- 30 秒模式切换率
- 3 分钟模式停留时长
- 变体选择占比
- 券领取率 / 使用率 / 兑换成功率
- 裂变转化率
- 风险拦截率
- Push 到达率 / 打开率
- 离线缓存命中率

## 7. 人工依赖

当前仓库推进到正式集成前，需要人工补齐：

- uniCloud 阿里云服务空间
- HBuilderX 安装路径
- Push 厂商账号与 key
- 券码/活动运营账号权限
- 正式埋点项目配置
- A/B 平台或分桶实现归属

## 8. 回滚策略

- 配置按版本回滚。
- 实验按实验键停用。
- Push 按 campaign 取消。
- 券码批次按状态冻结。
- 风控规则按版本回退。
