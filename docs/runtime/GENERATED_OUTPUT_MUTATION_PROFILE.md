# Generated Output Mutation Profile

## Purpose

Document which content/runtime commands rewrite generated outputs, which paths they touch, and how agents should restore state when generated churn is only validation evidence.

## Source And Generated Boundary

| Path | Role | Mutation rule |
| --- | --- | --- |
| `fixtures/test-inputs/**` | Canonical synthetic source fixtures. | Do not mutate in command-safety goals. Edit only for an explicit contract change or documented validator mismatch. |
| `scripts/content/**` | Executable source of truth for synthetic pack build, export, select, and smoke. | Read-only in this goal. |
| `output/test-input-pack/**` | Generated build/export/select/smoke reports and runtime bundles. | May be regenerated; restore unless explicitly committed. |
| `mobile/fixtures/runtime/scenarios/**` | Generated scenario bundles consumed by the legacy mobile fixture surface. | May be regenerated by export; restore unless explicitly committed. |
| `mobile/fixtures/runtime/current/**` | Generated selected scenario projection. | May be rewritten by select/smoke; restore unless explicitly committed. |
| `mobile/fixtures/runtime/*.json`, `mobile/fixtures/runtime/index.js` | Legacy root mobile fixture export surface. | Treat as generated but source-adjacent; prefer Worktree. |
| `output/stage-e0/**` | Legacy mobile fixture export bundle/report. | Generated; restore unless explicitly committed. |

## Command Profiles

### `build:test-inputs`

- Exact command: `npm.cmd run build:test-inputs`
- Wrapper: `scripts/content/build-synthetic-test-pack.ps1`
- Node entry: `scripts/content/build-synthetic-test-pack.mjs`
- Reads: `fixtures/test-inputs/manifests/test-pack.manifest.json`, `fixtures/test-inputs/manifests/scenario-index.json`, `fixtures/test-inputs/publications/publications.json`, `fixtures/test-inputs/scenarios/**`
- Writes:
  - `output/test-input-pack/reports/source-index.json`
  - `output/test-input-pack/reports/build-report.json`
- Mutation type: generated-output-mutating.
- Expected churn: timestamps and derived summaries.
- Restore when validation-only:
  - `git restore -- output/test-input-pack/reports/source-index.json output/test-input-pack/reports/build-report.json`
  - Recheck `git status --short`.

### `export:runtime-scenarios`

- Exact command: `npm.cmd run export:runtime-scenarios`
- Wrapper: `scripts/content/export-runtime-scenarios.ps1`
- Node entry: `scripts/content/export-runtime-scenarios.mjs`
- Reads: same source fixture set as `build:test-inputs`.
- Writes:
  - `output/test-input-pack/reports/source-index.json`
  - `output/test-input-pack/reports/build-report.json`
  - `output/test-input-pack/reports/export-report.json`
  - `output/test-input-pack/runtime/*.bundle.json`
  - `mobile/fixtures/runtime/scenarios/*.bundle.json`
- Mutation type: generated-output-mutating.
- Expected churn: exported timestamps and derived bundle content if source fixtures changed.
- Restore when validation-only:
  - `git restore -- output/test-input-pack mobile/fixtures/runtime/scenarios`
  - Inspect untracked generated bundles before removal.

### `select:runtime-scenario`

- Exact npm/PowerShell command: `npm.cmd run select:runtime-scenario -- -ScenarioId s01_normal_full_matrix`
- Wrapper: `scripts/content/select-runtime-scenario.ps1`
- Wrapper argument: `-ScenarioId <scenario_id>`
- Underlying Node argument emitted by wrapper: `--scenario-id <scenario_id>`
- Reads: `mobile/fixtures/runtime/scenarios/<scenario_id>.bundle.json`
- Writes:
  - `mobile/fixtures/runtime/current/runtime.bundle.json`
  - `mobile/fixtures/runtime/current/scenario-meta.json`
  - `mobile/fixtures/runtime/current/expected-outcomes.json`
  - `mobile/fixtures/runtime/current/bootstrap-config.json`
  - `mobile/fixtures/runtime/current/content-sync-delta.json`
  - `mobile/fixtures/runtime/current/content-detail.json`
  - `mobile/fixtures/runtime/current/entitlement-snapshot.json`
  - `mobile/fixtures/runtime/current/pricing-preview.json`
  - `mobile/fixtures/runtime/current/experiment-assign.json`
  - `mobile/fixtures/runtime/current/commercial-offer.json`
  - `mobile/fixtures/runtime/current/quota-status.json`
  - `mobile/fixtures/runtime/current/promo-preview.json`
  - `mobile/fixtures/runtime/current/referral-summary.json`
  - `mobile/fixtures/runtime/current/reward-summary.json`
  - `mobile/fixtures/runtime/current/campaign-landing.json`
  - `mobile/fixtures/runtime/current/profile-benefits.json`
  - `mobile/fixtures/runtime/current/index.js`
  - `output/test-input-pack/reports/current-scenario.json`
- Mutation type: generated-output-mutating.
- Expected churn: selected scenario projection and `selected_at` timestamp.
- Restore when validation-only:
  - `git restore -- mobile/fixtures/runtime/current output/test-input-pack/reports/current-scenario.json`
  - If the selected scenario was already the same but timestamps changed, still restore unless the goal intends to refresh generated state.

### `export:mobile-fixtures`

- Exact command: `npm.cmd run export:mobile-fixtures`
- Wrapper: `scripts/bootstrap/export-mobile-runtime-fixtures.ps1`
- Node entry: `scripts/bootstrap/export-mobile-runtime-fixtures.mjs`
- Reads: `backend/**`, `shared/contracts/**`, fixture seed data referenced by `createLocalBackendRuntime()`.
- Writes:
  - `mobile/fixtures/runtime/bootstrap-config.json`
  - `mobile/fixtures/runtime/content-sync-delta.json`
  - `mobile/fixtures/runtime/content-detail.json`
  - `mobile/fixtures/runtime/entitlement-snapshot.json`
  - `mobile/fixtures/runtime/pricing-preview.json`
  - `mobile/fixtures/runtime/experiment-assign.json`
  - `mobile/fixtures/runtime/index.js`
  - `output/stage-e0/mobile-runtime-fixtures.bundle.json`
  - `output/stage-e0/mobile-runtime-fixtures.report.json`
- Mutation type: generated-output-mutating and source-adjacent.
- Expected churn: export timestamp and serialized runtime fixture bundle.
- Restore when validation-only:
  - `git restore -- mobile/fixtures/runtime output/stage-e0`
  - Prefer Worktree because this touches root legacy mobile fixture surfaces, not only scenario/current generated projections.

### `validate:test-inputs`

- Exact command: `npm.cmd run validate:test-inputs`
- Writes: `output/test-input-pack/reports/validation-report.json`
- Mutation type: report-mutating.
- Expected churn: `generated_at` timestamp.
- Restore when validation-only:
  - `git restore -- output/test-input-pack/reports/validation-report.json`
  - If untracked, inspect path and remove only after confirming it is generated.

### `smoke:test-inputs`

- Exact command: `npm.cmd run smoke:test-inputs`
- Behavior: runs export, then selects `s01_normal_full_matrix`, `s02_general_fallback`, and `s03_teen_unavailable`.
- Writes:
  - all `export:runtime-scenarios` outputs
  - all `select:runtime-scenario` current projection outputs
  - `output/test-input-pack/reports/smoke-test-input-pack.json`
- Mutation type: generated-output-mutating.
- Restore when validation-only:
  - `git restore -- output/test-input-pack mobile/fixtures/runtime/scenarios mobile/fixtures/runtime/current`
  - Re-run `git status --short`.

## Non-Mutation Expectations

The commands above must not write:

- `fixtures/test-inputs/**`
- `scripts/content/**`
- app source behavior
- Expo config
- package dependencies
- database schema
- auth, payment, push, or production config

If any generated-output command touches those areas, stop and report `NEED_HUMAN` before continuing.
